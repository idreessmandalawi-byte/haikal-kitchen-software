# دليل تغليف مشروع HTML/CSS إلى برنامج سطح مكتب (.exe)

## 📁 هيكلية المجلد المطلوبة:
ضع هذه الملفات بجانب ملفات مشروعك الحالي كما يلي:

```text
my-project/
├── index.html           <-- ملفك الحالي (دون أي تعديل)
├── icon.ico             <-- أيقونة برنامجك بصيغة .ico
├── css/                 <-- مجلد التنسيقات الخاص بك (إن وجد)
├── js/                  <-- ملفات الجافاسكريبت الخاصة بك (إن وجد)
├── images/              <-- الصور الخاصة بك (إن وجد)
├── main.js              <-- ملف التشغيل المُجهز
├── package.json         <-- ملف إعدادات الحزمة والتغليف
└── preload.js           <-- ملف وسيط اختياري
```

---

## 🚀 خطوات التشغيل والتغليف:

1. **تثبيت الحزم (مرة واحدة):**
   افتح موجه الأوامر (CMD أو PowerShell) داخل مجلد المشروع ونفذ:
   ```bash
   npm install
   ```

2. **تجربة التطبيق محلياً قبل التغليف:**
   ```bash
   npm start
   ```

3. **توليد ملف التنفيذي (.exe):**
   ```bash
   npm run build
   ```

ستجد ملفات الـ `.exe` الجاهزة داخل مجلد جديد يُنشأ تلقائياً باسم `dist/`:
- نسخة تنصيب عادية (Setup Installer).
- نسخة محمولة تعمل مباشرة بدون تثبيت (Portable).
